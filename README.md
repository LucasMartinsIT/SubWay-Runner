# Subway Runner 🏃‍♂️

A 3D endless runner mobile game built from scratch using Unity and C#. 

This project focuses on delivering a smooth and highly responsive gameplay experience, featuring procedural level generation and mobile-optimized controls. 

## 🎮 Features

- **Fluid Player Mechanics:** Complete movement system including running, jumping, sliding, and seamless lane switching.
- **Mobile-First Controls:** Swipe-based input logic optimized for Android and iOS touch devices.
- **Procedural Generation:** Infinite game environments dynamically generated at runtime to ensure varied gameplay.
- **Obstacle Detection & Animation:** Fully animated player character with precise hitbox detection.
- **Economy & Scoring:** Integrated coin collection mechanics and scoring system.
- **Responsive UI:** Clean menus including Start, Pause, and Game Over screens.
- **Cross-Platform Ready:** Configured for deployment on both Android and iOS.
- **Clean Architecture:** Well-organized Unity scenes and modular, clean C# scripting.

## 🛠️ Technologies Used

- **Game Engine:** Unity 3D
- **Programming Language:** C#
